# Data Analysis Project

## 📊 Project Title
Retail Sales Data Analysis Using Python

## 📌 Project Description
This project performs data cleaning, analysis, and visualization
on a retail sales dataset using Python.

## 🛠️ Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn

## 🔍 Data Cleaning
The dataset was cleaned by:
- Removing duplicate records
- Handling missing Sales values
- Handling missing Profit values
- Converting Order Date into datetime format

## 📈 Data Analysis
The project analyzes:
- Sales by Category
- Sales by Region
- Sales trends over time
- Relationship between Sales and Profit
- Distribution of Sales
- Correlation between numerical variables

## 📊 Visualizations
The project contains:
1. Bar Chart – Sales by Category
2. Pie Chart – Sales by Region
3. Line Chart – Sales Trend
4. Scatter Plot – Sales vs Profit
5. Histogram – Sales Distribution
6. Heatmap – Correlation Analysis
